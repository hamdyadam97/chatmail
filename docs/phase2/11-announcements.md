# 11. التعاميم (المرحلة الرابعة — الشريحة الثانية)

## 11.1 النموذج

| العنصر | السلوك |
|--------|--------|
| التشفير | كل تعميم = مجموعة MLS (`Conversation(type=announcement)`): الناشر + الجمهور المحلول فقط؛ المحتوى `{عنوان، نص}` رسالة MLS واحدة |
| الجمهور | `users` / `department` / `branch` / `institute` / `all` — يحله الخادم من العضويات السارية لحظة الإعداد ويثبّت لقطة في `announcement_recipients` |
| صلاحية النشر | `announcements.publish` في وحدة الهدف (مركزي لـ`all`؛ لكل موظف محدد: وحدة تضم إحدى عضوياته) |
| لا مستلمين خفيين | الجمهور معلن لكل مستلم (`/audience/`)، والعميل يطابقه مع روستر MLS ويحذّر بالأحمر من أي عضو غير معلن؛ والخادم يرفض أي Welcome لجهاز خارج الأعضاء وأي توسيع للعضوية |
| الرقم المرجعي | `{معهد}-TAM-{سنة}-{تسلسل:05}` بقفل صف |
| الاستلام / الاطلاع | `delivered_at` عند أول جلب للتفاصيل، `read_at` عند الفك والعرض |
| الإقرار | توقيع Ed25519 بمفتاح الجهاز فوق `"announcement-ack-v1\n" ‖ JSON قانوني {acknowledged_at, announcement_id, content_hash, device_id, user_id}` — مربوط ببصمة الـciphertext؛ يُخزن التوقيع كدليل (ليس توقيعًا نظاميًا قانونيًا) |
| الموعد النهائي والتذكير | تذكير يدوي (مرة في الساعة كحد أقصى) لمن لم يقر؛ ومهمة مجدولة `manage.py send_announcement_reminders` (cron كل ساعة) تذكّر مرة يوميًا بدءًا من 24 ساعة قبل الموعد |
| تقرير الالتزام | المستلمون/الاستلام/الاطلاع/الإقرار/المتأخرون لكل موظف — للناشر ولحاملي `announcements.track_ack` في وحدة الهدف؛ وصفي فقط ولا يفتح المحتوى |
| السحب | علامة وصفية تمنع الإقرارات الجديدة؛ معلن أن النسخ المفكوكة لا تُسترجع |

## 11.2 تحسين عام في طبقة التوصيل: Welcome واحد لعدة أجهزة

قياس فعلي على `mls-rs` (Node): حجم رسائل المصافحة ≈ 335 بايت لكل عضو — إنشاء مجموعة من 1000 عضو: Commit ‏286KB وWelcome ‏335KB في أقل من ثانية. كانت كل Welcome تُخزن نسخة لكل جهاز (500 جهاز ≈ 84MB لتعميم واحد). الآن:

- `welcome_recipients`: Welcome يُخزن **مرة واحدة** ويُوجَّه لعدة أجهزة (`recipient_device_ids`)، والرؤية عبر API تبقى لمالك الجهاز المعنون فقط (SEC-07).
- حد حجم مستقل للمصافحة (1MB ≈ 3000 جهاز) مع إبقاء رسائل التطبيق عند 256KB.
- العميل يجزّئ استعلامات الدليل والـclaim إلى 200 معرّف، ويرسل Welcome واحدًا — يستفيد منه خيط المراسلات أيضًا.

## 11.3 حدود معلنة

- الجمهور مقيّد بـ`ANNOUNCEMENT_MAX_RECIPIENTS` (افتراضيًا 1000). «جميع المعاهد» الأكبر من ذلك يحتاج تقسيمًا لعدة تعاميم أو تقنية MLS أخرى (مثل الانضمام الخارجي) — غير مبنية.
- المستلم بلا أي جهاز مفعّل التشفير يمنع النشر (الواجهة تسميه)؛ البديل المقصود ألا يُنشر تعميم يستحيل على بعض مستلميه فكه.
- موظف ينضم للوحدة بعد النشر لا يصله التعميم (لقطة الجمهور ثابتة).
- لا مرفقات في التعاميم بعد.
- التذكير المجدول يحتاج cron (لا Celery بعد).
