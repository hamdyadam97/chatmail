# 17 — تطبيق الموبايل (PWA)

قرار المستخدم: **تطبيق ويب يُثبَّت (PWA)**، لا متاجر. نفس الكود ونفس التشفير على الموبايل والكمبيوتر. وطريق المتاجر (Capacitor) يبقى ممكنًا لاحقًا فوق هذا العمل نفسه.

## ما بُني

| الجزء | التنفيذ |
|-------|---------|
| التثبيت | `public/manifest.webmanifest` (standalone، rtl، start_url `/mail/inbox`، اختصارات «رسالة جديدة» و«المحادثات»)، وأيقونات 192/512 وmaskable 512 وapple-touch-icon 180، ووسوم iOS في `index.html`، وتسجيل `sw.js` عند بدء التطبيق |
| دعوة التثبيت | `features/install/InstallPrompt.tsx`: Android عبر `beforeinstallprompt`، وiPhone بشرح «مشاركة ← إضافة إلى الشاشة الرئيسية». تُغلق وتُحفظ محليًا |
| الهيكل | تحت عرض `md` (768px): العمود الجانبي يُخفى ويظهر **شريط سفلي** (البريد، المحادثات، التعاميم، الموافقات، المزيد)، والبحث أيقونة، والهوامش أصغر، واحترام safe-area في iPhone |
| البريد | لوحة واحدة في كل مرة: القائمة (المجلدات قائمة منسدلة + زر رسالة جديدة) ← الرسالة بملء الشاشة مع زر رجوع |
| المحادثات | القائمة أولًا (لا فتح تلقائي لأول محادثة على الموبايل) ← المحادثة بملء الشاشة مع رجوع، ولوحة الأعضاء بملء الشاشة |
| التنبيهات | على الموبايل شريط واحد في كل مرة بالأولوية: تثبيت ← مفتاح الاستعادة ← الإشعارات |
| nginx | `location = /manifest.webmanifest` بنوع `application/manifest+json`، لأن mime.types في Ubuntu يخلو منه (هذا الموقع فقط) |

## الإشعارات على الموبايل

- **Android (Chrome/Edge):** تعمل من المتصفح ومن التطبيق المثبّت.
- **iPhone:** تعمل **بعد التثبيت فقط** وعلى iOS 16.4 أو أحدث (قيد من Apple). شريط التثبيت يذكر ذلك.

## الاختبار

`npm run test:ui` §7ج بشاشة 412×915 لمس، وهو جزء من 51/51:
- تهيئة التشفير، والشريط السفلي، وعدم وجود تمرير أفقي في الوارد والرسالة والمحادثات.
- فك مراسلة وفتحها بملء الشاشة ثم الرجوع.
- المحادثات تبدأ بالقائمة.
- الـmanifest وأيقوناته متاحة، والـservice worker مسجّل.

## حدود

- لا عمل دون اتصال (مقصود: كل شيء يمر بالخادم مشفّرًا، ولا نخزن صفحات قديمة).
- لم يُجرَّب على أجهزة فعلية بعد، بل على محاكاة Edge بمقاس هاتف. التجربة على Android وiPhone حقيقيين مطلوبة.
