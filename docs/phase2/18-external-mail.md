# 18 — البريد الخارجي (استقبال وإرسال)

قرار المستخدم: كل موظف عنوانه `<اسم البريد>@m3had-system.cloud`. الاستقبال على **سيرفرنا** (Postfix)، والإرسال عبر **Brevo**.

## المبدأ: منفصل ومُعلَّم

البريد الخارجي **ليس مشفّرًا طرفًا لطرف من مصدره**. الخادم يراه لحظة وصوله أو خروجه، وهذا متأصل في البريد الخارجي، فهو تطبيق مستقل (`external_mail`) لا يمس المراسلات المشفّرة، وتعلّمه الواجهة بوضوح. لكنه **لا يُخزَّن مقروءًا أبدًا**:

| | ما يحدث |
|---|---|
| الوارد | Postfix ← أنبوب ← `ingest_external_mail`: يُحلَّل في الذاكرة، وتُشفَّر المرفقات بصيغة مرفقات العميل نفسها (`corr-attachment-v1`)، ويُختم المحتوى لكل جهاز نشط للمستلم (X25519 + HKDF `corr-external-seal-v1` + AES-GCM، وAAD `corr-external-v1\|message\|device`). الرسالة الأصلية `.eml` تُحفظ مرفقًا مشفّرًا |
| الصادر | المتصفح يرسل النص إلى `/api/v1/external-mail/send/` (غير E2EE بطبيعته — منفصل عن نقاط E2EE)، والخادم يسلّمه لـ Brevo، ثم يختم نسخة المرسل لأجهزته |
| المخزَّن مقروءًا | بيانات توجيه فقط: العناوين، وMessage-ID، والأوقات، والأحجام، ونتيجة التحقق من المرسل |
| HTML | لا يُعرض أبدًا: يُحوَّل نصًا على الخادم (بلا سكربت ولا تتبع)، وتُحفظ الروابط نصًا |

## العناوين والصلاحيات

- الافتراضي: `اسم المستخدم@النطاق`. والمسؤول (`accounts.manage_users` على الموظف) يضع **اسم بريد** مختلفًا كي لا تصبح أسماء الدخول علنية، ويفعّل أو يعطّل الاستقبال والإرسال لكل موظف من صفحة الموظف.
- الاستقبال مفعّل افتراضيًا، و**الإرسال معطّل افتراضيًا**.
- `ahmed+anything@` يصل لأحمد.
- الحساب المعطّل أو الاستقبال المعطّل ← العنوان غير موجود ← Postfix يرفضه أثناء المحادثة (لا backscatter).
- مستلم بلا جهاز نشط ← «أعد لاحقًا» (75)، فيحتفظ Postfix بالرسالة ويعيد المحاولة.

## الحماية

- **انتحال المرسل:** DKIM (dkimpy، مع مواءمة نطاق التوقيع بنطاق From) أو SPF من Postfix (`policyd-spf`، ونثق بالترويسة العليا فقط). غير الموثّق يظهر بتحذير أحمر في القارئ وأيقونة في القائمة.
- **الفيروسات:** اختياري عبر `clamd` (`CLAMD_SOCKET`). المصاب يُحذف ويُذكر اسمه. ودون clamd تظهر للموظف «لم تُفحص المرفقات».
- **الإرسال:** لا إرسال لعناوين النطاق نفسه (للزملاء: المراسلات الداخلية)، و20 مستلمًا كحد أقصى، و10MB مرفقات، و50 رسالة يوميًا لكل موظف (`EXTERNAL_MAIL_DAILY_LIMIT`)، وتحذير صريح قبل الإرسال.
- **التدقيق:** `external_mail_received` و`external_mail_sent` و`external_mailbox_updated` بلا أي محتوى.
- **الإشعار:** عام «وصلك بريد خارجي» (لا مرسل ولا عنوان على شاشة القفل).

## النشر

1. ملف البيئة: `EXTERNAL_MAIL_DOMAIN=m3had-system.cloud` و`BREVO_API_KEY=…` (يضعه المسؤول بنفسه).
2. DNS: `MX @ → mail.m3had-system.cloud` (أولوية 10)، وSPF `v=spf1 include:spf.brevo.com -all`، وسجلات توثيق الدومين من Brevo، و`_dmarc`.
3. `sudo bash deploy/scripts/install-mail.sh`: Postfix **للاستقبال فقط** (لا يرسل شيئًا). يرفض العمل إن كان المنفذ 25 لبرنامج آخر أو كان `main.cf` لغيرنا، ولا يغيّر الجدار الناري (يطبع الأمر فقط). وخريطة العناوين تُحدَّث كل دقيقتين (`correspondence-mailmap.timer`).
4. فتح المنفذ 25 الوارد في جدار Hostinger إن وُجد.

تحقق: الإعداد مقبول من `postconf` الخاص بـ Postfix 3.8.6 (نسخة Ubuntu 24.04) مستخرجًا مؤقتًا.

## حدود معلنة

- الجهاز المعتمد **بعد** وصول رسالة لا يفتحها (لم تُختم له)، إلا عبر الاستعادة بالمفتاح. نفس نموذج تاريخ MLS.
- لا قوائم سوداء (RBL) افتراضيًا (Spamhaus يرفض المحلّلات العامة). يمكن إضافتها لاحقًا.
- لا إحالة لمراسلة داخلية مشفّرة إلى الخارج (منع تسريب مقصود).
